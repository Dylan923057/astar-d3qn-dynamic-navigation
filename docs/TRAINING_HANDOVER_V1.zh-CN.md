# A*训练引导与动态风险交接（v1）

## 研究问题

A*训练时直接帮助D3QN收集有效的前进经验；当静态规划的下一步附近出现动态障碍，是否应停止代选，让D3QN从环境交互中学习避让？引导最终全部撤掉后，网络能否更快、更稳定地独立到达终点？

本批研究的是**训练行为策略**，区别于已有的静态foundation迁移、25%示范回放和运行时路线输入实验。所有旧数据和入口保留。实验方向是候选方案，接入检查不能证明性能或论文创新。

## 已有证据与选择理由

- 现有距离奖励下，运行时路线输入的5个seed最终平均安全成功率为95.6%，无路线输入94.4%，提升小且学习速度不一致。
- 去掉距离奖励的seed 0，两组21次贪婪验证都未成功；训练阶段偶尔成功，无动态障碍时也大量等待。仅展示路线不足以提供稳定的训练信号。
- 因此本批保留两组共用的原距离奖励，只改训练动作的来源。前期A*直接收集前进经验，后期交回网络，评估从开始到结束都由网络单独选动作。

## 五组对照

|标识|训练时A*介入|要回答的问题|
|---|---|---|
|unguided|0|无A*的D3QN基线，仍有共用的距离奖励|
|astar_fixed|每步80%概率|持续介入是否形成依赖？|
|astar_decay|80%线性降到0，第100000步起为0|仅按时间退出是否足够？|
|astar_risk_decay|同一时间计划，但有动态风险时取消介入|在冲突位置交回网络是否更好？|
|astar_budget_matched|每10000步介入次数与同seed的risk组完全相同，时刻随机|risk组若更好，是否仅因为A*用得更少？|

matched组自动在该seed的risk组完成后运行。它只读取risk组的训练动作计数，不读取验证成功率，不选择超参数。若匹配次数被破坏，入口报错，禁止将该次运行当作有效对照。

## 实现合同

1. **初始化**：全部从随机网络开始，每个seed的五组完全相同。网络、优化器、D3QN探索随机数与已有dense unguided组一致；额外A*选择使用独立随机数，不改变网络初始化。
2. **输入**：保持现有5×15×15和4个标量的网络形状，新增路线通道与子目标标量对所有组都置零。有效信息为静态局部地图、动态当前帧和前两帧、最终目标方向。该形状兼容运行时实验模型，不能直接加载旧4通道foundation。
3. **教师**：从当前机器人位置重新用静态A*求到原终点的下一步；可以从偏离路线的位置重新接上。只知道静态地图，不使用动态障碍真实路线、隐藏相位或下一步真实位置。没有离线示范预填充和额外监督损失。
4. **风险代理**：检查A*下一格及其曼哈顿半径1内，是否出现在动态当前帧或前两帧。命中则取消这次A*介入，使用原epsilon-greedy候选动作。这是保守的观测风险代理，未做运动身份匹配或精确未来预测，不是安全保证。
5. **探索**：每一步先按原epsilon-greedy生成D3QN候选，再按本组规则决定是否用A*替换。原epsilon仍为1.0→0.05，150000步衰减；A*混合会改变实际行为分布，这正是本批处理变量。risk交接不添加动态动作屏蔽；网络可以前进、绕行或等待，也可能碰撞。
6. **奖励相同**：普通步−0.01，曼哈顿距离每减少1增加0.05、增加1减少0.05，STAY额外奖励0；到达+10、碰撞−1沿用原终止分支。没有引导组专用奖励。
7. **环境与训练相同**：原40×40地图和起终点，全图路线池、每回合3–5障碍、每步移动，最多300步、碰撞终止、仅静态动作屏蔽。每组200000环境步，回放10000、batch64、500步后开始更新，预期199501次更新。
8. **场景配对**：验证固定50场景，与旧foundation验证完全一致；各组同seed第n回合的训练场景一致。因回合长度不同，不能声称相同环境步正在经历同一个场景。初始检查验证地图SHA、路线池SHA和场景相位。
9. **评估**：epsilon=0，A*规划器与代选逻辑不被调用，训练计数/随机数/优化器不被评估改变。全部学习曲线由网络独立完成；每约10000环境步、在回合边界验证，保存该检查点权重和全部失败轨迹。
10. **输出**：独立`outputs/whole_map_91701_training_handover_v1`和`results/whole_map_91701_training_handover_v1`。已有目录拒绝覆盖。权重检查点只用于推理评估；未保存完整回放及环境状态，不声称支持中途完整恢复训练。

## 先跑什么、何时扩大

第一批：seed 0、1，五组各200000步。两seed是可行性检查，不作为最终论文统计结论。先看全曲线、A*撤掉后的100000步、最后5次验证，不能只挑最好一次。

记录最终安全成功率、动态碰撞率、超时率；首达90%/95%的步数、后续所有检查达标起点、学习曲线面积；实际A*介入次数；静态无动态障碍的网络独立到达情况。对全部检查点失败轨迹检查等待、反复移动、碰撞发生时位置及离终点的静态剩余距离。

判据在第一批正式训练前写明：risk组在两seed中都应能独立走通静态地图，动态最后5次验证平均安全成功率至少90%；若达不到，先核查基础到达能力与失败轨迹，不直接把种子扩大。通过后固定设置补seed 2–4；方法优势看跨seed配对曲线面积与碰撞率，不把“跑得通”当作“优于对照”。若只胜过time-decay、没胜过同次数随机介入组，不归因于风险判定。

现有图只是第一张。正式论文还需至少两张结构不同的地图或不同起终点任务，并在冻结方法/配置后使用各自独立的验证场景；另保留未用于开发和选模型的最终test集合，最后才评估。不能依据已反复查看的50验证场景宣称未知场景泛化。本入口不读取test。

## 论文定位与已有工作

“A*+D3QN”“专家帮助探索”“引导随训练退出”本身都不能当作新发现。已有研究结合专家建议、风险/不确定性和时间调节，例如[Abouelazm等（2026），Uncertainty-Aware and Temporally Regulated Expert Advice](https://arxiv.org/abs/2605.30576)。其摘要强调不确定性触发建议及建议时长/频率控制；本文候选机制则针对**只懂静态地图的规划教师**，在动态冲突附近取消教师动作。两者任务、骨干与教师能力不同，尚不能据此断言独创性。

已有D3QN导航研究也比较稀疏任务奖励与距离势奖励，例如[DWA-D3QN（2026）](https://www.mdpi.com/1999-4893/19/7/528)。本批共用距离奖励是为了隔离引导方式；稀疏奖励结果保留为已有诊断，不把“没有距离奖励”定义成唯一合法D3QN基线。

若取得稳定证据，小论文的候选贡献是：静态教师与动态交互的适用边界、按风险交接机制、匹配教师介入次数后的效果及失败模式。毕业论文可增加多地图/多起终点，以及从观测历史学习更准确的运动风险判断。若机制对照没有优势，报告真实结论并另定方法，不能承诺发表或预设有利结果。

## PowerShell单行命令

准备检查（不会训练）：

```powershell
python scripts/run_training_handover.py --check --seeds 0 1 2 3 4
```

第一批正式训练，依次完成seed 0、1的五组，matched组自动匹配risk组的训练介入计数：

```powershell
python scripts/run_training_handover.py --train --seeds 0 1
```

全部第一批完成后分析（不会重新训练）：

```powershell
python scripts/analyze_training_handover.py --seeds 0 1
```

第一批通过后补充seed 2–4（暂不执行）：

```powershell
python scripts/run_training_handover.py --train --seeds 2 3 4
```

# DQfD与风险筛选消融：冻结协议

依据：[Hester等，DQfD，AAAI 2018，arXiv v4](https://arxiv.org/html/1704.03732v4)。核心流程对应算法1、损失式2–4及附录：永久示范、独立预训练、带示范优先级奖励的PER、单步与10步Double-DQN平方TD、大间隔专家损失与参数L2。没有以prefill替代DQfD。

## 新增方法

- A `dqfd`：永久示范分区加10000容量在线FIFO；预训练仅采样示范，在线从两分区共同按PER采样，示范比例由优先级决定。专家损失持续仅用于示范，在线数据专家损失为0；没有在线A*动作代选。
- B `dqfd_bound`：与A相同，仅将`reward + discount × bootstrap`组成的完整单步和多步TD目标裁剪到[-6,10]，终止目标也处理；不裁剪Q输出、不分别裁剪回报或bootstrap。A/B预训练前状态与示范字节完全相同，训练后的网络和采样轨迹可因唯一干预而不同。
- C `advice_bound_margin_no_risk`：继承原完整组合，唯一行为修改是`observed_risk`始终返回False，使代选和辅助监督同时取消风险拒绝。静态合法动作、实际执行匹配、碰撞终止(-1)样本不参加辅助监督保留，代选和监督均按原100000步日程归零。

## 训练前固定的参数与适配差异

| 项目 | 固定值/依据 |
|---|---|
| 单步/10步TD | 平方误差；权重1/1，依原文公式；不是旧组合Huber损失 |
| 专家监督 | 大间隔0.8，权重1，永久示范持续监督；附录值 |
| L2 | 网络全部权重和bias的平方和×1e-5，附录值；不另加Adam weight_decay |
| PER | alpha=0.4，beta=0.6；beta在线200000步内线性升至1，预训练固定0.6 |
| 优先级 | abs(单步TD误差)+来源bonus：在线0.001，示范1.0；附录值。新增项用历史最大误差，重复采样索引用本批最大误差更新 |
| IS | 对单步TD、多步TD、示范大间隔使用IS权重，全回放最小概率规范化；L2不按样本加权 |
| 预训练 | 20000个batch更新，仅用于A/B；固定计算预算适配，原文为750000，不能称完全复现原Atari实验 |
| 示范 | seed91702641，固定128次训练场景尝试；静态A*下一动作被三帧观测风险筛选拒绝时WAIT；只保留实际安全到达的完整轨迹。没有查询未来障碍、动态路线相位来选动作 |
| 示范筛选 | 排除原50、旧500和尾段新500的路线组合/物理场景；这些集合只用于身份排除，不读取表现。128尝试结束即停止，不按模型效果增加数量，不调整教师或超参数 |
| 网络/优化器 | 复用D3QN及Adam，LR=3e-4，gamma=.99，batch64，target同步250更新，梯度范数10；保留项目值，原文target周期10000 |
| 观测/动作/奖励 | 固定原地图与起终点，每回合3–5动态障碍，300步上限；5×15×15及4标量中引导附加量为0，5动作，原曼哈顿进展奖励。没有Atari的图像下采样/帧重复/对数奖励转换 |
| 静态动作约束 | 行为、单步/多步bootstrap和专家大间隔竞争动作屏蔽静态非法动作；不屏蔽动态风险，是导航适配 |
| 多步边界 | 只在同一回合累计，goal/collision终止禁止bootstrap；timeout/预算截断保持bootstrap，尾部使用实际长度及gamma^长度；在线成熟最多延迟9步，回合结束刷新 |
| 在线 | 所有新方法200000环境步；500步开始每步更新一次，共199501次；epsilon1→0.05/150000步，沿用原协议。A/B总更新219501，C总更新199501 |

示范量、成功尝试数、被丢弃轨迹和A*实际调用/搜索/耗时在`data/whole_map_91701_dqfd_comparison_v1/freeze_manifest.json`及`demonstration_episodes.json`记录。二进制无损压缩示范与源码/config摘要一起在训练前冻结；A/B各seed共享同一份。训练入口拒绝覆盖任何已有run。

与历史模型配对比较的是预训练前完整基础D3QN状态（online/target网络、Adam、更新计数、探索RNG），并核对其可重建状态与历史五seed指纹一致。A/B离线预训练的额外计算与数据成本必须报告，不能将在线AULC的提升解释为相同总训练成本下的优势。A*查询次数和真正的缓存未命中搜索次数分别记录，C的被动诊断标签查询计入查询成本。

## 验证与报告

训练沿用原50场景、每10000在线步跨界后的回合结束点验证，epsilon=0普通网络自主动作，没有教师或动态shield。DQfD的在线0步验证发生在离线预训练之后，预训练权重额外保存但不用于最终检查点选择。

统一汇总11种方法×5seed：原六消融、无代选监督消融、监督尾段延期、上述A/B/C。旧方法复用已保存200000步模型，不重新训练。统计单位为seed，均值±样本标准差ddof=1；所有方法相对原完整组合，以及B相对A，给出逐seed配对差值与差值的均值±SD。

报告全程及0–8/8–10/10–14/14–20万步AULC、最后五次均值、原退出窗90000–120500与新退出窗130000–160500最低成功率、合并窗口、最终自主成功/动态碰撞/超时、等待/循环/其他超时。尾段使用原预注册判据同时看两个窗口和后段，避免只报告原窗口改善。逐条检查实际失败轨迹；等待/循环分类复用原代码。

成本表记录示范量、预训练/在线更新数、预训练与在线耗时、整组wall time、A*查询/搜索数与耗时，以及共享的一次示范生成成本。历史未记录的实际耗时/A*计数留空，不能用文件创建时间估算；`training_cost_means.csv`相应均值也为空。

最终确认只使用尾段训练前新冻结的500场景，SHA256 `051c083a8a185ac1738ad71debd3508cca7a20020319009eabe132062c130318`。不使用旧500调参，不在训练中访问新500表现。全部55个最终模型通过审计后才开始统一评估；不选择最佳检查点。它是同地图新组合确认，不是跨地图泛化。

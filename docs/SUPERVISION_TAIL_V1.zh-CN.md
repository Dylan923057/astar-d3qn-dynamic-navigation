## 只改变辅助动作监督日程

`t`表示已完成的环境动作步数；每次更新使用当前`t`。A*代选沿用原来的一基下一动作步计时，概率`0.8×max(0,1−t/100000)`，第100000个动作起严格为零。新的监督子类只覆盖`imitation_weight()`，没有赋值或延长控制代选的`decay_steps`。

辅助监督权重为：

- `0 ≤ t ≤ 80000`：`1−t/100000`，连同浮点运算顺序与原实现一致。
- `80000 < t < 140000`：`0.2×(140000−t)/60000`。
- `t ≥ 140000`：严格为`0`，不再计算或应用监督标签。

| 环境步t | 原监督权重 | 新监督权重 | 原/新A*代选概率 |
|---:|---:|---:|---:|
| 0 | 1 | 1 | 0.8（尚未执行动作） |
| 80000 | 0.2 | 0.2 | 0.16 |
| 100000 | 0 | 0.133333 | 0 |
| 120000 | 0 | 0.066667 | 0 |
| 140000 | 0 | 0 | 0 |
| 200000 | 0 | 0 | 0 |

80000步边界连续，浮点差约5.55×10⁻¹⁷；80000步及以前的全部整数权重与原组逐项完全相等，代表批次的梯度更新和完整学习状态也逐比特相同。监督日程理论面积从50000增加到54000（+8%）；这个对照检验指定日程的整体作用，不能把收益单独归因于延长退出时刻而排除累计监督量的变化。

其余保持原正式组合设置：固定40×40地图91701、起点(3,3)、终点(36,36)、全图路线池v2，每回合3–5个动态障碍；最多300步，碰撞终止；200000环境步、199501次更新；同一网络、观测、TD目标限制[-6,10]、margin=0.8、10000容量均匀在线回放、batch64、500步开始更新；epsilon由1降至0.05，衰减150000步。普通进步奖励`−0.01+0.05×曼哈顿距离减少量`，终点+10、碰撞−1，均为原规则。

标签仍只针对实际执行动作匹配静态A*、静态合法、当前及前两帧观测风险筛选通过、真实转移未碰撞的回放经验。没有额外示范池，没有路径/子目标输入或动态安全保护，没有引入未来障碍信息。网络接口保留5通道15×15和4标量，其中路径通道与子目标标量恒零。

## 学习曲线与失败原因报告

沿用原50验证场景及原约10000环境步的验证频率，包括0步及最后200000步共21次；检查点在回合末发生，使用实际步数计算，不改评估触发规则。

完整报告每个seed、均值±样本标准差（ddof=1）、全程及0–80k/80–100k/100–140k/140–200k分阶段AULC、最后五次均值、最终碰撞率/超时率，以及：

- 原退出窗口`90000–120500`步最低成功率与对应实际检查步数。
- 新退出窗口`130000–160500`步最低成功率与对应实际检查步数；窗口同宽，整体后移40000步。
- 合并窗口`90000–160500`最低成功率和14–20万步的最低值，避免只展示原窗口改善。
- 每个检查点、两窗口、14–20万后段、最终验证的碰撞次数及超时分类。各窗口总数是重复检查点的观察次数之和，不代表互不重复的独立场景。

所有失败类别从原始完整轨迹重新计算，超时互斥分类：WAIT比例≥50%为等待超时；否则至少20次移动且重复移动比例≥50%，或最后60位置有2–12步周期，为循环超时；剩余为其他超时。原始等待/反复移动/周期标签可以重叠，完整保留，不凭成功率猜失败原因。

`paired_differences.csv`逐seed比较原/新窗口最低值、合并窗口、14–20万AULC和最低检查点后移情况。预先固定的描述性判断：若原窗口改善而最低检查点后移，新或合并窗口及后段AULC不支持改善，报告“低谷后移迹象”；若合并窗口最低值和后段AULC均提高，报告“持续改善迹象”；其他为混合结果。比较后移使用名义10000步检查点，避免把回合末几十步差异当作推迟。结论仍须联合五seed全部曲线和失败类别，描述性判断不等于显著性检验。

真实Q、实际TD目标和监督权重均来自`value_learning.csv`；监督标签抽样数量也逐1000步记录。历史权重只有策略网络，不能用加载后同步的目标网络冒充旧训练目标。所有未来障碍信息只允许用于事后诊断。

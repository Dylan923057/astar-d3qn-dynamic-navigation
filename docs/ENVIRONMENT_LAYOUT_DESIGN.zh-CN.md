# 环境布局设计

更新时间：2026-08-11

本阶段只冻结静态环境布局，不启动训练，也不改变网络、奖励、epsilon 或 replay 配置。地图仍然是固定 manifest；三种 replay 在同一张地图上分别独立训练，不做跨地图泛化声明。

## 分层

| 层级 | 地图 | 用途 | 当前判定 |
| --- | --- | --- | --- |
| 校准环境 | `calibration_20x20_map_01..05` | 检查 Uniform 是否能在5张稀疏、分散的混合形状障碍图上分别稳定学习 | Uniform已完成，5/5成功 |
| 较难校准环境 | `calibration_hard_20x20_map_01..05` | 比简单校准图增加明确绕行和转弯压力，用于正式 replay 比较前验证 | 每张独立训练，未启动 |
| 放大校准环境 | `calibration_40x40_map_01..05` | 在更大、分散的混合形状障碍图上检查 Uniform 稳定性和路径学习压力 | 已生成，未启动训练 |
| 主实验 | `office_40x40` | 房间、墙、门和主走廊 | 静态候选 |
| 主实验 | `parcel_station_40x40` | 分拣岛、工作台和交叉通道 | 静态候选 |
| 主实验 | `warehouse_40x40` | 平行货架、横向通道和中部瓶颈 | 静态候选 |

校准集包含5张独立的20x20固定地图，种子为1100至1104，不再使用长墙分割地图。每张地图的障碍由十字、T形、矩形和L形等小块组成，分布覆盖整张地图并保持30%的占用率；起点固定为 `(1,1)`，终点固定为 `(19,19)`。每张地图由一个独立策略训练和评估，不能把5张图混入同一个策略。

主实验图由矩形墙体/货架和固定门洞组成。门洞位置直接写在生成器中，不能由随机散点替代。A* 仍只生成名义路径和示范转移，不进入奖励。

放大校准集包含5张独立的40x40固定地图，固定种子为1500至1504。每张地图有360个障碍格，占用率为22.5%；障碍由单格、短条、L形、2x2、2x3和3x3等中等大小形状随机散布，端点周围一格保持开放。地图被划分为16个10x10分区，每区严格放置22或23个障碍格；最大障碍连通团不超过24格。生成器不再用最小绕行步数筛选布局，避免障碍为了制造A*通道而呈现人为连线；同时仍要求10至30次转弯，并保留至少50条采样到的等长最短路径。起点为 `(1,1)`，终点为 `(39,39)`。

其中“绕行比”定义为 `A* 步数 / 起点到终点的 Manhattan 步数`；“瓶颈宽度”和“障碍块/门洞/路线选择”是布局设计登记值，不从障碍密度推断难度。主场景当前 A* 路径保持单调前进，但必须穿过内部门洞、横向通道或瓶颈，因此转弯数和局部结构仍有差异。后续若需要更强的非单调绕行，只新增明确的布局消融，不修改这批基线地图。

5张校准图均限制最大障碍连通团不超过9格。使用100个随机等价A* tie-breaking种子检查时，每张图产生99至100条不同的36步最短路径，路径并集覆盖114至149个自由格。由于终点 `(19,19)` 位于右下角，它只有两个相邻入口，所以完全顶点不相交路径最多为两条；布局优化目标是增加中段路线选择，而不是违反这一几何上限。

## 文件与使用方式

- 生成器：`src/astar_d3qn/maps/structured.py`
- 生成脚本：`scripts/generate_structured_maps.py`
- 校准 manifest：`maps/structured_calibration/maps.json`（5张固定地图）
- 较难校准 manifest：`maps/structured_calibration_hard/maps.json`（5张固定地图）
- 放大校准 manifest：`maps/structured_calibration_40x40/maps.json`（5张固定地图）
- 主场景 manifest：`maps/structured_main/maps.json`
- 校准配置：`configs/structured_calibration.yaml`
- 较难校准配置：`configs/structured_calibration_hard.yaml`
- 放大校准配置：`configs/structured_calibration_40x40.yaml`
- 主场景配置：`configs/structured_main_40x40_static.yaml`

生成脚本只执行 A*、校验和 JSON 写入，不创建环境训练过程。例如重新生成固定 manifest：

```powershell
python scripts/generate_structured_maps.py --group calibration
python scripts/generate_structured_maps.py --group calibration_40x40
python scripts/generate_structured_maps.py --group main
```

校准配置与主场景配置都设置了 `independent_maps: true`。校准实验必须传 `--map-index 0..4`，主场景实验必须传 `--map-index 0..2`；任何一组地图都不能混成一个共享策略。

每次训练运行的两张策略路径图统一写入 `paths/`：文件名使用 `_best_path.png` 和 `_final_path.png` 防止覆盖，PNG标题同时标注 `BEST PATH` 或 `FINAL PATH`。不再创建独立的 `best_paths/` 与 `final_paths/` 目录。

## 冻结后的判断顺序

1. 只做静态生成/加载、A* 路径和 manifest hash 校验。
2. 获得用户明确同意后，在校准图先验证 Uniform 的冻结 greedy 成功率和局部循环情况。
3. 校准通过后，使用相同预算在三张主场景上比较 Uniform、Prefill 和 Persistent Demo。
4. 静态比较冻结后，再为名义 greedy 路径设计横穿、迎面和同向三类动态障碍；动态障碍不写入静态 A* 地图。

### Map 1 动态校准场景（已实现，未正式训练）

配置：`configs/dynamic_calibration_40x40_map01.yaml`。

- 只使用 `calibration_40x40_map_01`，起点 `(1,1)`，终点 `(39,39)`，静态障碍和 A* 名义路径保持不变。
- 三种 replay 使用完全相同的三个动态障碍；障碍路线不写入静态地图，也不进入 A* 示范规划。
- 横穿障碍路线为 `[(5,13),(6,13),(7,13),(8,13),(9,13)]`，来源是 Uniform 静态 `final_path` 的中段交互位置 `(7,13)`，每步移动一格。
- 迎面障碍路线为 Prefill 静态 `final_path` 的连续段 `[(31,17),...,(31,23)]`，从 `(31,23)` 沿路径反向运动，每步移动一格。
- 同向慢行障碍路线为 Persistent Demo 静态 `final_path` 的连续段 `[(20,35),...,(28,35)]`，从 `(24,35)` 沿路径正向运动，每两步环境步移动一格。
- 三条路线均经过静态障碍校验，不包含起点/终点，初始位置互不相同，并使用确定性往返运动。
- 观测为 `4×15×15`：静态障碍、当前动态障碍、上一帧动态障碍、上两帧动态障碍；另有 2 个归一化目标位移标量。
- 奖励和 epsilon 暂时完全沿用静态基线，不加入动态安全距离奖励、不修改贪婪策略。
- A* 示范重新生成，动态通道为零；这表示名义静态能力，不是假装 A* 已经学会动态避障。

当前不执行正式训练，不使用 `learning_starts=2000`，不扩大 replay 容量，也不加入 A* 路径奖励。

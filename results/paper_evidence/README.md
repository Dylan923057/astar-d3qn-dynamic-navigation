# 论文实验结果归档

本目录按照实验完成时间和训练方法整理可上传 GitHub 的正式结果。归档仅复制分析与追溯所需文件，不替代 `outputs/` 中的原始产物。

## 时间线

### 01：2026-09-17 至 2026-09-21，回放基线

- 目录：`01_2026-09-17_to_21_replay_baselines/`
- 地图：`irregular_workcell_91701`、`irregular_workcell_91702`
- 训练种子：每张地图 5 个

### 02：2026-09-21 至 2026-09-22，风险交接核心试验

- 目录：`02_2026-09-21_to_22_risk_handover/`
- 地图：`irregular_workcell_91701`
- 训练种子：0、1、2
- 方法：`fixed_00`、`fixed_10`、`fixed_25`、`time_decay`、`risk_handover`
- 测试动态障碍密度：1、3、5、7
- 定位：当前小论文方向的首轮核心证据。
- 结论：机制已触发，但 `risk_handover` 未优于基线；风险样本替代静态示范的当前实现不成立，需要继续诊断风险样本内容与分配方式。
- 可用性：正式负结果。可以用于方法动机和消融分析，不能表述为性能提升。

### 03：2026-09-22，安全干预诊断

- 目录：`03_2026-09-22_safe_intervention_diagnostic/`
- 地图：`irregular_workcell_91701`
- 训练种子：0、1、2
- 方法：`intervention_only`、`safe_replay_04`、`safe_replay_08`
- 定位：失败机制诊断，不是当前主攻方向。
- 结论：训练期替换危险动作切断了碰撞负反馈，三个方法均显著低于 `time_decay`。
- 可用性：仅用于研究过程、失败分析和毕业论文讨论，不作为小论文主方法结果。

## 目录结构

- `config/`：对应实验 YAML 配置。
- `dataset/`：冻结的数据清单与场景审计文件。
- `foundations/`：基础模型资格、训练过程和有效配置；不含权重。
- `runs/<map>/<method>/<seed>/`：按地图、训练名称和种子分类的正式运行文件。
- `analysis/`：原始汇总 CSV、JSON、图表和复现实验报告。

每个运行保留以下文件（存在时）：

- `result.json`：最终指标、运行状态、配置/数据/代码哈希和机制统计。
- `fork_audit.json`：分叉一致性与批次构成。
- `training.csv`：训练过程及风险机制是否触发的审计数据。
- `validation_curve.csv`：冻结验证集学习曲线。
- `validation_details.csv`：逐场景验证结果。
- `test_evaluation.csv`：冻结测试集逐场景结果。

## 总索引

- `experiment_index.csv`：64 个正式运行的可读索引。
- `experiment_index.json`：与 CSV 对应的机器可读索引。
- `provenance_groups.csv`：按代码、配置和数据哈希划分的来源组。
- `SHA256SUMS.csv`：归档文件大小和 SHA-256，用于上传后核验。

## 当前论文使用顺序

1. 用阶段 01 描述基础方法、示范比例对照和跨地图稳定性。
2. 用阶段 02 作为风险经验回放的正式首轮验证，报告机制触发与负结果。
3. 阶段 03 只用于说明为什么暂不采用安全干预，不与当前风险回放主线混写。
4. 后续实验必须沿用阶段 02 的冻结数据划分和核心指标，并在新的独立阶段目录中归档。

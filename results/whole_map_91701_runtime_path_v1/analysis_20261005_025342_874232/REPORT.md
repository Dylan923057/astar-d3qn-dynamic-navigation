本批结果的结论：
- seed0的引导组首次达到90%约在12万步，无引导约在16万步；但引导组最终84%，低于无引导92%。加快学会到达与最终安全性是不同结论。
- seed1两组首次达到90%都在约14万步；引导组最终100%，无引导90%。此前的持续超时没有延续到终局。
- 两seed最终平均安全成功率：无引导91%，引导92%；引导组最终动态碰撞平均6%、超时2%，无引导动态碰撞平均9%、超时0%。差异方向随seed改变，不能据此证明稳定优越。
- 四份最终权重在原地图、无动态障碍、epsilon=0时均66步安全到达。最终失败主要出现在动态交互：无引导seed0/1分别4/5次动态碰撞；引导seed0为6次动态碰撞和2次循环移动超时，seed1无失败。
- 引导seed0两条终局超时轨迹均没有等待，移动300步，末60步分别呈2步和4步周期；是局部循环，不能解释为一直等待。静态BFS仍能到达终点，但这不证明任意动态时刻存在安全路线。

首次达到阈值仅为稀疏检查点结果，不能称为稳定收敛。两seed的最终平均成功率只作描述，不把100个场景当100个独立训练seed。
这次比较同时加入路线通道和前方引导点，不能单独归因于其中某一项。训练起点、探索和回放与旧foundation复用实验不同，不能把两批差异单独归因于引导形式。
没有保存中间权重，不能把曲线中的最好检查点当作可加载的最好模型，也不能在分析时选最好检查点替代预先固定的终局比较。

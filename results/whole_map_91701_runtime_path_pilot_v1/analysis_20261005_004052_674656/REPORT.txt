本轮结论：当前“随机初始化 + 实时路线输入 + 5万步动态训练”未形成稳定导航策略。
四个最终模型的动态安全成功率均为0%；原地图去除动态障碍后，四个模型也全部超时。
这表明最终失败不只发生在动态冲突中；不能据此认定A*方向信息无效，也不能把原因直接归结为训练步数、奖励或示范缺失。
补充核对旧Pure曲线后：旧实验seed0/1在约5万步时也均为0%，在20万步才达到100%/94%。因此，5万步失败本身并非新增异常，不足以支持改变为静态预训练流程。

- unguided/path_guided，seed0/1，四个run均完成50000环境步、49501更新，最终权重和completion存在。
- 两组同seed初始网络/优化器/随机状态指纹一致，登记配置一致，在线回放容量10000，无A*示范。

- 分析没有读取test，没有启动训练，没有修改源输出。静态诊断epsilon=0，原地图/起终点/奖励/动作/碰撞规则，只移除动态障碍。

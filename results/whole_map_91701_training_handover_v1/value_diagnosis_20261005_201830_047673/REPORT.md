# A*训练引导的价值学习诊断

本次查训练失败机制，未启动正式训练，未修改当前训练配置或已有权重；未使用test。

## 已确认的故障

持续80%A*代选的seed 0，网络给实际不应高分的后退、等待动作赋予高值，D3QN又把这些估计放入下一步更新目标。这能解释训练由A*带领时大量成功、关闭A*后却停住或往返的现象。强引导怎样最初触发这些误差，尚未完整复现，不能只归因于一个超参数。

核对项目实现后，实际执行动作与保存到回放的action一致；到达和碰撞均设置terminated，分别对应奖励10和−1；终止更新不引用未来Q；静态动作掩码在argmax之前应用；策略网络选择、目标网络评价；目标同步条件正确。新收集样本的原始观测未被后续step修改。相关18项D3QN测试通过。

奖励上限核查：普通非终止步最多0.04，折扣0.99，终点10且立即终止。所以任何物理轨迹的折扣回报不超过10；千级估值不是距离奖励累积的合理结果。

## 故障的具体位置

沿原静态A*路径检查，同一个距终点仅一格的位置(36,35)：

|持续引导检查点|正确向右的Q|网络偏好的错误动作及Q|
|---|---:|---|
|10082步|10.04|向上12.76|
|50075步|8.40|向左88.06|
|200000步|17.75|向左1153.51|

正确终止动作一开始已经能拟合到约10，但其他动作虚高并压过它。前一格的非终止更新若引用这些虚高的下一步分值，便会得到超过真实回报上限的训练目标。这个过程不要求实际执行那个后退动作；它来自max选择的估计值。

在最终静态停滞位置(9,3)，网络给等待1466.04、向前的DOWN1462.98，持续等待294步。该位置的全部动作都严重虚高，最高分排序恰好落在等待上。具体位置与Q值另见前次分析中的static_action_value_diagnostics.json。

## 同起点、同数据的短更新对照

每个分支加载相同10082步权重，用新Adam、相同1000条数据、完全相同的64个mini-batch各更新64次；目标网络训练中保持冻结，更新后重新同步用于诊断重算。下表只评价这份诊断拟合数据，不能代替独立验证或正式训练效果。

|短诊断处理|执行动作Q均值（开始均为13.18）|与静态教师不同的下一动作比例|
|---|---:|---:|
|原DDQN更新|13.44|73.0%|
|改用教师下一动作估值|13.14|71.7%|
|只将TD目标限制在回报边界[−6,10]|10.06|70.7%|
|目标边界加已执行且观测风险低的教师动作margin|9.98|3.7%|

margin仅用于执行动作等于静态教师建议、观测当前/前两帧的邻近风险代理未命中且该次执行未碰撞的样本，共841条。它是诊断中的监督约束，不能假定静态教师在所有动态场景都正确。参数采用项目已有的margin=0.8、权重1.0。

这说明：原更新在局部探针里仍维持虚高；仅限制目标数值可以降低总体Q，却不会自动纠正动作排序。明确的动作学习约束在拟合数据上改善了排序，但尚未证明自主到达、动态避障或跨seed泛化得到改善。改用教师bootstrap也未在本短探针里充分解决问题。

# 最新实验：A*探索、动作学习与TD目标限制

这是2026-10-07完成的正式200000步实验分析包，六组×seed0、1，共12次完整训练。请先读本文件和[完整报告](REPORT.md)，然后按[分析请求](GPT_ANALYSIS_PROMPT.md)独立核对数据。这里有失败、恢复和引导退出时的退化，不只展示最后成功的模型。

## 先区分实验

本包是`whole_map_91701_value_repair_v1`，不是2万步pilot，不是旧静态foundation迁移，不是运行时把A*路径输入网络的实验。

所有组从同seed配对的随机初始状态开始，不加载foundation，不预填充示范，也没有25%示范回放。A*只在训练前期概率性代选动作；评估全程关闭。路径通道和子目标标量始终为0。

## 六组到底改变了什么

|---|---|---|---|---|
| 1 | unguided_raw | 无 | 无 | 无 |

| 4 | advice_bound | 有 | 有 | 无 |

- A*：已知静态地图，从当前格重新规划，概率从约0.8按环境步线性降至100000步的0。建议下一格若与当前或前两帧观测中的动态障碍曼哈顿距离≤1，取消A*代选并交回普通epsilon贪婪策略。取消后不强制等待，也不保证D3QN动作安全。
- 辅助动作学习：只监督经验池中实际执行、与静态A*建议相同、通过上述风险筛选、没有实际碰撞反馈的动作。要求其Q值高于其他静态合法动作0.8；辅助损失权重从1线性降至100000步的0。不是奖励加0.8，也不是完整DQfD。
- 目标限制：仅截断Double DQN用于更新的TD目标，不截断网络输出、不改变动作或奖励；100000步后仍保留。依据当前reward和gamma可证明[-6,10]是保守折扣回报范围。Q输出可能暂时超过10。

风险筛选在全部A*组中相同，没有单独关闭风险筛选的对应分支；不能从本包单独证明风险筛选有效。也没有“无A*代选但保留同样动作监督”的分支，不是三个开关的完整2×2×2实验。

## 共同条件

- 地图`irregular_workcell_91701`，40×40，起点(3,3)，终点(36,36)，静态最短路径66步。
- grid SHA：`789e02a19e945736e2ae78fa54163dd58e069df568d777f76577f6b8ccede0ff`。
- 全图路线池v2，design SHA：`d9a57b3af3fb88bdef4601b07115a0ea8d7f92c040de3a9797b1439d768de3be`。
- 每回合随机3、4、5个动态障碍，每步移动；最多300步，碰撞终止。五动作：上、下、左、右、等待。只屏蔽静态非法动作。
- 实际基础观测为15×15窗口：静态、当前动态、前两帧动态，共4通道，另有2个归一化目标位移标量。各组网络为5通道+4标量，多出的路径通道和两个子目标标量全部置0。
- 每组200000环境步，199501次更新；在线回放10000，均匀采样，batch64，500步起学习，每环境步更新1次。
- epsilon从1.0降至0.05，150000环境步完成；gamma=0.99，学习率0.0003，目标网络每250次更新同步。
- 普通步奖励：-0.01+0.05×(旧曼哈顿距离-新曼哈顿距离)。接近一步+0.04，远离一步-0.06，等待-0.01。到达终点独占+10，碰撞独占-1；超时没有额外惩罚。
- 同seed六组的网络、优化器、回放和随机状态初始SHA一致；后续行为不同会自然改变回合长度和经历。同第n个训练回合使用同一个场景序列，同一环境步不保证处于同一回合。
- 共用50个固定验证场景，每10000步左右验证一次，加初始检查点共21次。全部epsilon=0、网络独立选动作，不调用A*或风险保护；本包未使用test。

## 最终结果及全程表现

最终三个百分数依次为安全成功／动态碰撞／超时，分母均为50回合。

| 组别 | seed0 | seed1 | 两seed平均全程安全AULC | 两seed最后5次安全成功均值 |
|---|---|---|---:|---:|
| 1 | 92% / 8% / 0% | 90% / 10% / 0% | 31.56% | 96.8% |
| 2 | 94% / 6% / 0% | 100% / 0% / 0% | 44.44% | 97.0% |
| 3 | 0% / 0% / 100% | 98% / 2% / 0% | 6.61% | 31.4% |
| 4 | 100% / 0% / 0% | 100% / 0% / 0% | 58.63% | 98.4% |
| 5 | 98% / 0% / 2% | 0% / 2% / 98% | 36.79% | 22.0% |
| 6 | 100% / 0% / 0% | 100% / 0% / 0% | 90.59% | 99.4% |

AULC按实际记录环境步对21次安全成功率作梯形积分并除以200000。它比较整个训练期间的自主验证表现，不是最后成功率、训练成功率或一次连续评估。最后5次均值覆盖约160000–200000步。

需要同时解释的现象：

1. 第1组最终能学会，但约14–16万步才首次记录到≥90%。第3组seed0全程0%，seed1约18万步才恢复到94%。
2. 第5组约1万步已有94%/90%，约2万步98%/100%，约9万步掉到10%/12%，约10万步均0%；退化在完全退出引导之前已开始。不能仅把失败归因于第10万步关掉A*。
3. 第6组早期较好，退出附近仍出现退化：seed0在100107步为70%，seed1在110095步为62%；之后恢复。第4组最终也100%，不能声称第6组最终成功率优于第4组。
4. 第3组seed0、第5组seed1最终在无动态障碍原地图也超时；失败不全是动态碰撞，包含持续等待和重复移动。
5. 第3组seed0原始TD目标峰值618.48，seed1峰值114.07；第5组峰值50.16/44.92；第6组原始峰值12.01/12.29，实际用于更新的目标截断在[-6,10]。全动作Q峰值包含非法动作，不应单凭其峰值推断策略。
6. 第4、6组最终各50场景普通D3QN回放与原记录完全一致。清零动态观测的同状态候选比较显示部分动作改变规避了下一步碰撞。碰撞判定仅在动作选择后用于事后解释，没有输入策略；它不是训练安全保护或未知场景泛化证明。

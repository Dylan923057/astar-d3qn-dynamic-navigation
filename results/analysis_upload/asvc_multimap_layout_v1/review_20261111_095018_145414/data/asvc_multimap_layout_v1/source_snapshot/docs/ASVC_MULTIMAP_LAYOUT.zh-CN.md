# ASVC 多地图布局补实验 v1

本协议对应 2026-11-07 用户授权：在同一生成规则的三张新静态布局上独立从头训练六方法，并在一张几何预选地图上补两个关键消融。计划新增 **90+10=100 次训练、2000 万在线交互步**。不启动其他扩展，不重复原图训练，不合并旧回放或 50 万步多任务成绩。

原始资料入口为 `HANDOFF.md`、`docs/EXPERIMENT_INVENTORY.zh-CN.md`、`docs/ASVC_CURRENT.zh-CN.md`、`data/asvc_current_method.json` 及 `results/analysis_upload/*/LATEST.md`。前两份交接记录主要属于较早研究；本轮按当前 ASVC 登记及用户本次授权执行。旧 Office/Parcel/Warehouse 不进入本轮。

## 已有与缺失

原图 irregular_workcell_91701 六方法各五 seed 的 20 万步训练共30次已完成；原图独立500评估、密度1/3/5/7评估及版本一致的消融优先复用。`data/asvc_multimap_layout_v1/existing_evidence.json` 保存模型SHA、完成登记、原始训练/验证日志SHA和历史最新说明；`results/asvc_multimap_layout_v1/existing_runs.csv` 为逐次清单。CE/QDagger 密度补测的最新完成数据在 `results/asvc_fixed_ce_qdagger_density_v1/`，比10月底上传包更新。本轮不会重新测原图仅为补计时。

新增三图90次主对比、10次消融及对应100套最终500评估，启动前全部为缺项。进度持续写入 `results/asvc_multimap_layout_v1/run_progress.csv` 和 `progress.json`；完成项必须匹配本轮完整配置、地图、方法、训练seed、源码冻结及最终模型SHA后才能跳过。已有结果仅作为原图证据，原图验证间隔较疏，不能伪造为每4000步记录。

## 地图冻结

实际生成器为 `astar_d3qn.maps.adaptation.irregular_problem(seed,size=40,demo_seed=7400)`。保持矩形/L/T设备岛规则、目标占比0.23（最低0.20）、岛间一格间隔、起终点曼哈顿三格保护、全自由空间连通、最短路绕行不超过12步、200次地图尝试和每图2000次设备岛尝试。岛状障碍按整块加入，因此实际占比可略高于23%。仅地图seed变化；参考路径平局随机源demo_seed保持7400。

候选顺序在算法训练前登记为91704–91733，选首三张唯一、可达且**原v2路线池和动态采样规则完全可用**的布局。91704因路线池严格间距配额不可满足被拒绝，保留原因；未改变筛选阈值。接受91705、91706、91707，实际占比23.0%、23.375%、23.0%，最短路均66步。地图JSON、栅格SHA、自由格度分布、参考路径净空等见 `maps_frozen.json` 和 `map_*/geometry.json`。

消融地图按“参考静态路径上平均净空倒数最大，其次map_seed最小”选定91707。这是训练前的描述性几何规则，未读取任何策略成绩。三图以及全部训练seed均保留，不能因表现不佳换图/换seed。

`map_seed`决定静态布局；`train_seed=0..4`决定网络初始化、探索与经验采样，二者严格分开。每次训练地图及起终点固定，不读取其他地图模型或foundation。

## 动态场景和示范

路线池复用 `configs/dynamic_route_pool_v2.yaml` 的完整设计：240条合理路径、HI/替代通路/背景路线20/18/10，原分类阈值及场景接受规则不变。每回合动态障碍数从3、4、5均匀抽取；3障碍按1/1/1，5障碍2/2/1，4障碍在2/1/1与1/2/1间抽取。障碍沿冻结路线连续往返，不逐方法调整。

每图独立冻结50验证和500测试场景的任务、路线、相位、方向及顺序；两集合的完整路线组合不重复。训练用**冻结的确定性程序式无限序列**，而不是有限场景池：本图路线池、采样源码、初始随机状态/seed、排除规则和每训练seed的128条前缀共同登记。采样只用方法无关的局部随机源；第k个回合在所有方法中对应同一场景，各方法回合长度可不同。训练与示范排除全部验证/测试路线组合。每次恢复保存已消耗序号及两套采样RNG，不重新从序列开头采样。

示范共享给本图的A*初始化、DQfD、QDagger；每图沿用原规则的128次尝试预算与固定示范seed91702641，只保留实际成功且无碰撞完整回合，失败尝试也记录。保留数分别为6719/7573/6659条（成功99/111/98次）。这是等生成预算；不为了复制原图7260条而额外采集。教师为静态A*＋输入中当前及历史可观测风险拒绝为WAIT；不读取未来。生成环境步、查询、搜索、耗时与预训练成本单列。

## 六方法与消融

直接复用现有网络和学习器，不重新实现其损失：

|方法|初始化/离线更新|在线学习与教师|
|---|---|---|
|D3QN|随机初始化，无示范/离线更新|均匀在线回放，无教师、无TD约束|
|A*初始化＋TD约束|本图示范FIFO预填，零离线更新|普通一步DDQN，完整目标裁剪[-6,10]；无在线教师|
|DQfD|本图示范，20000次离线更新|永久示范、PER、10步TD、平方TD损失、大间隔及L2；无TD约束|
|QDagger任务适配版|本图示范，20000次离线更新|学生采集、学生在线回放、3步DDQN Huber和策略蒸馏；T=0.1，离线权重3，在线3×max(1−t/120000,0)；无A*代选/TD约束/持续下限|
|CE|无离线示范|当前ASVC同一教师、硬筛查、代选和TD约束；监督仅替换为掩码CE(T=1)，监督下限0.1|
|完整ASVC|无离线示范|代选初值0.8线性衰减，100000步退出；大间隔0.8、权重max(0.1,1−t/100000)，完整TD目标裁剪[-6,10]|
|去TD约束|同ASVC|仅关闭完整TD目标裁剪；不裁剪Q输出|
|后期完全撤监督|同ASVC|仅将监督下限改0，100000步退出；早期仍监督|

QDagger是预算/教师/网络的任务适配，不能称为原Atari完整复现。新两消融只在91707各五seed，完整方法直接复用主实验。

共同输入为5×15×15和4标量，其中路线通道与额外两个子目标标量始终置零；观测及历史构造严格沿用当前固定任务版本，不在本轮另改。动作5（含WAIT），共用静态动作掩码，不掩盖动态障碍。奖励step=-0.01、progress=0.05、stay=0、collision=-1、goal=10。gamma=0.99，batch64，在线回放10000，Adam学习率0.0003，目标同步250次更新，梯度范数裁剪10。epsilon按在线步数1→0.05，在150000步线性衰减。

500步起每步更新一次，共199501在线更新；DQfD/QDagger额外20000离线更新。TD使用真实动作和真实转移。超时300步，目标/碰撞terminated不自举；超时truncated仍自举。在线预算截断也自举，多步尾部用实际长度折扣，不能跨回合累积。

## 验证、测试和计时

零步先评估随机模型；DQfD/QDagger另外保留预训练前状态和评估、预训练后在线0步评估。随后每跨过4000步，在该回合结束时评估50场景，记录真实交互步数（最多漂移一个300步回合）；预算末尾强制评估。最终固定200000步模型，绝不选中间最优。

验证和最终500均epsilon=0、纯网络、无教师代选、无动态保护、无更新，静态掩码保留。评估前后校验学习器/优化器/RNG内容指纹。教师和更新入口的禁止调用补丁在预检中实际检查。测试集不用于地图选择、调参或日程，旧多任务两个测试池不启用。

AULC对成功率验证点作分段线性积分并除以区间长度；固定0–50k、0–200k、100–200k。报告后半实际验证点最低成功率、最终500安全成功/动态碰撞/超时。每图按五训练seed算均值和样本SD，ASVC与各对照按同train_seed作差；跨三图先按同方法同seed宏平均，再报告五seed统计。缺项保留为空，失败不剔除、不替代为0。最终500和50验证分开保存。

统一GPU设备、每进程1个CPU线程、最多2训练进程；所有阶段保持相同并发上限。记录离线更新、在线环境/学习、评估、断点写入耗时。实际并发占用会影响耗时，数据标注为受控并发下的测量，不当作独占设备基准。A*查询次数/缓存未命中搜索次数/查询耗时和在线教师成本单列；自主推理延迟仅在无教师评估时测量。不会为了补旧结果计时重训。

## 恢复与失败

独立路径为 `configs/asvc_multimap_layout_v1.yaml`、`data/asvc_multimap_layout_v1/`、`outputs/asvc_multimap_layout_v1/`、`results/asvc_multimap_layout_v1/`。`freeze.json`保存完整有效配置、输入SHA和源码快照；启动及续训先验证。每约4000步和离线1000更新保存最新完整状态：网络、目标网络、Adam、回放/PER、采样器、挂起多步队列、环境历史/运动状态、场景流、教师缓存、全部RNG、进度和日志。加载权重不作为续训。

数值失败保留failure.json、failure_state.pth、已写日志和原seed；不自动增加裁剪、改参数或换seed。调度器通过OS文件锁拒绝重复队列和重复worker，匹配完成项直接跳过。意外中断可使用--resume，不能将源文件或冻结配置变更后混入旧身份。

## 实际命令

在仓库根目录PowerShell：

```powershell
# 初次准备；已冻结时只校验
& D:\softwares\Anaconda3\envs\astar-drl\python.exe -X utf8 -u scripts/prepare_multimap_layout.py --freeze
# 地图/场景、学习器语义、六方法短程、完整恢复及自主评估检查
& D:\softwares\Anaconda3\envs\astar-drl\python.exe -X utf8 -u scripts/run_multimap_layout.py --preflight
# 首次启动（本轮预检通过后由助手直接执行）
.\scripts\start_multimap_layout.ps1 -Workers 2
# 断点续跑，自动跳过身份一致的完成项
.\scripts\start_multimap_layout.ps1 -Resume -Workers 2
# 状态与汇总，不训练
& D:\softwares\Anaconda3\envs\astar-drl\python.exe -X utf8 scripts/run_multimap_layout.py --status
& D:\softwares\Anaconda3\envs\astar-drl\python.exe -X utf8 scripts/analyze_multimap_layout.py
```

Windows后台启动使用Start-Process -WindowStyle Hidden，并将标准输出与错误写入本轮outputs；不能再同时运行第二个同队列调度器。后续只补缺项，不重新生成地图或按成绩改协议。

本轮结论限定为**同一地图生成规则下，不同静态布局的独立训练验证**；不能宣称零样本新地图泛化，也不预设ASVC或任何教学方式占优。

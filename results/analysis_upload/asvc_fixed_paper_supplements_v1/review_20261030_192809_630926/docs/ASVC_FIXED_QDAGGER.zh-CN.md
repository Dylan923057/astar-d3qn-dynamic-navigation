# 固定任务QDagger适配预实验与CE最终确认

本轮只新增QDagger seed0、1各20000离线更新＋200000在线环境步，以及CE五个最终模型的500场景确认。复用当前大间隔五seed的500结果和固定任务D3QN/DQfD seed0、1学习曲线，不训练这些旧组，不混入50万步多任务研究。

## 原文机制、本次实现与差异

参考[论文](https://arxiv.org/abs/2206.01626)、[官方代码](https://github.com/google-research/reincarnating_rl)、[DQN配置](https://github.com/google-research/reincarnating_rl/blob/e9df46e9a20bff1ad4df097258b454c72688c196/reincarnating_rl/configs/qdagger_dqn.gin)。官方参考按提交e9df46e9a20bff1ad4df097258b454c72688c196保存，带许可证和SHA；新学习器独立实现。

|机制|原文/官方实现|本次实现和适配|
|---|---|---|
|旧计算复用|教师策略和教师回放|原DQfD冻结7260条、107/128成功回合，不增加示范；生成成本单列|
|离线阶段|教师数据上TD＋策略蒸馏|20000梯度更新；这是预算适配，不是官方Atari完整预算|
|在线阶段|学生经验上的多步Q学习＋教师策略蒸馏|学生epsilon-greedy采集；均匀在线回放10000，不永久混入示范；教师不改变执行动作|
|教师|预训练RL教师的温度策略，默认策略KL|静态A*＋观测三帧半径1风险，拒绝则WAIT；确定性one-hot，无虚构教师Q；其KL等价于CE|
|学生|官方DQN/Atari配置|共同D3QN dueling骨干和Double-DQN；3步Huber，TD读取真实动作|
|蒸馏|官方T=0.1、系数3，代码没有T²系数|T=0.1、系数3；不额外乘T²；静态合法动作softmax|
|退出|论文6M/10M帧，官方代码也有分数反馈和最长周期|预先固定λ(t)=3max(1−t/120000,0)，20万步的60%；与分数无关|
|优化|官方学习率/更新频率/回放设置|lr=0.0003、batch64、500步开始每步更新、每250更新同步、梯度裁剪10；保持本任务公共设置|
|终止|多步回报|到达/碰撞不自举；超时及20万预算截断自举；尾部按实际1/2/3步和gamma^n，不跨回合|

主方法/CE对不安全或碰撞转移取消教师标签；QDagger教师风险拒绝会明确给WAIT标签，不按已执行动作是否碰撞取消标签。二者的教师接口、筛查、预算和退出方式不同，本对比不是只替换监督损失的单因素实验。教师只接收静态地图与网络观测，不接收环境未来/路线索引/计数器。风险只读取当前机器人周围至多2格，历史最多2次自身单位位移，因此这些风险用到的格子在原半径7视野内；不使用历史通道外围重新投影的不可见格子。离线逐条核对7260个动作与教师一致。

路线通道与附加路线标量置零。沿用固定地图、(3,3)→(36,36)、3–5动态障碍、原观测、奖励、max_steps=300、静态合法动作掩码。无A*代选、TD目标裁剪、Q裁剪、0.1下限、风险软权重、PER或DQfD附加损失。

## 冻结、验证与恢复

独立配置configs/asvc_fixed_qdagger_v1.yaml，data/outputs/results同名目录。训练开始前冻结完整公共/算法配置、源码快照、示范和场景SHA、旧模型/曲线与只读副本。预检覆盖多步尾部/回合边界、终止与截断、真实动作TD、合法掩码、教师one-hot、退出、离线在线回放隔离、自主评估隔离、CPU/CUDA完整恢复。保留预检失败；数值失败不改参数重试。

每seed保存预训练前完整状态和原50自主评估，预训练后保存在线0步完整状态及50评估。学习曲线0步使用预训练后评估，预训练前单独列出。每跨10000在线步后的回合边界验证，记录实际步数；最终模型严格200000步。前5万、全程、后10万AULC线性积分真实步数，后半最低成功率取实际验证点。只比较同seed0/1，不混入另外三个主方法seed。两seed探索性，不宣称显著性。

教师查询在收集每个状态时只标注一次并缓存随经验保存；这是确定性教师对同状态的等价复用，查询数、实际蒸馏回放样本数分别记录。120000步起不再查询教师，不计算蒸馏；旧标签留在回放但不再使用。优化器与目标网络状态、在线回放和三步待决队列、环境工厂、当前环境/观测、随机状态、更新/预算计数和日志均进入原子完整断点。仅载入权重不是完整续训。

## 命令

```powershell
# 只做冻结和预检
python scripts/run_fixed_qdagger.py --prepare
# 已通过预检后，独立顺序训练两个seed
python scripts/run_fixed_qdagger.py --train
# 中断后显式完整恢复；不自动恢复非有限失败
python scripts/run_fixed_qdagger.py --train --resume
# 只汇总已有数据
python scripts/analyze_fixed_qdagger.py
# CE最终确认；已完成的seed和50场景批次直接复用
python scripts/run_fixed_ce_final500.py --run
```

本轮不跑QDagger的500场景，不用CE的500成绩调参，不扩seed/扫参/五seed/正式消融。CE最终50验证与500确认分开报告。所有旧冻结、模型和原始日志保留。

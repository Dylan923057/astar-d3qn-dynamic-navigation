# 静态 foundation 后的动态适应实验：五 seed 分析包

请先读本文件、summary_per_seed.csv、additional_metrics_per_seed.csv 和 paired_uncertainty.csv，再检查各 run 的曲线与场景明细。analysis_figures.png 展示验证学习曲线、静态导航保持率和逐 seed AULC。

## 协议与核验

- 四组各 seed 0–4，共 20 个 run，全部完成 200000 动态环境步和 200000 次增量更新；没有剔除 seed。
- 地图 irregular_workcell_91701，dynamic_route_pool_v2，3–5 个动态障碍；同 seed 共用 episode 索引场景序列。
- 每个 seed 恢复自己的合格静态 foundation 的完整状态，含 policy、target、optimizer、更新计数、1320 条 demo、8680 条在线经验和随机状态。
- 停止示范组不是从零训练的 Pure：它的 foundation 曾使用 A* 示范，只在动态阶段停止示范采样。
- 各组固定 1320 demo + 8680 online，总容量 10000。不能直接与此前 10000 online 的实验混合比较。
- epsilon 0.30→0.05，150000 步完成衰减；采用已验收确定性设置。
- 比例：停止示范 0%；固定25%为16/64；时间衰减前50000步16/64、随后50000步6/64、最后100000步0；Adaptive 复用原训练窗口控制器。
- 每10000步验证固定50场景，并评估一条固定静态起终点路线；独立200场景测试只评估最终模型。
- 初始静态路线全部66步；动态初始安全成功率依 seed 为48%、42%、32%、54%、68%。
- 原始完成标记、全部文件哈希、来源指纹、逐场景指标、400万批采样和共享场景序列均核验通过。verification.csv 保存核验摘要。

## 核心结果（均值 ± 样本标准差，n=5）

| 方法 | 最终验证安全成功率 | 全程安全成功 AULC | 最终测试安全成功率 | 平均 demo sample 数 |
|---|---:|---:|---:|---:|
| 停止示范 | 99.6% ± 0.89% | 0.8885 ± 0.0213 | 99.0% ± 1.00% | 0 |
| 固定25% | 99.2% ± 1.79% | 0.8968 ± 0.0308 | 97.4% ± 2.36% | 320万 |
| 时间衰减 | 98.0% ± 3.46% | 0.8977 ± 0.0225 | 98.6% ± 0.74% | 110万 |
| Adaptive | 98.4% ± 1.67% | 0.8962 ± 0.0298 | 98.9% ± 1.02% | 176.4万 |

本包的 AULC 是按0、10000、…、200000步的验证安全成功率作梯形积分，再除以200000。早期 AULC 对对应时间区间积分并除以区间长度。

## 事实与解释边界

1. 早期均值有改善：前20000步，停止示范 AULC 均值0.358，固定25%为0.511；前50000步分别0.6196和0.686。三种示范组在前50000步验证曲线一致，因此这段结果不能归因于 Adaptive 调度。前50000步固定25%相对停止示范在4个seed提高、1个seed降低，配对均值差0.0664，探索性95%区间为[-0.0756, 0.2084]；不能认定已经证明稳定改善。详细数据见early_paired_uncertainty.csv。
2. 早期静态导航存在退化：105个静态检查点中，停止示范失败8次，固定25%4次，时间衰减3次，Adaptive4次；各组所有 seed 最终均恢复静态到达。这里仅测试同一条固定静态路线，不代表完整静态导航泛化能力。
3. 全程 AULC 的方法差异很小且 seed 间方向不同。固定25%相对停止示范的配对差为 [0, +0.0615, -0.019, +0.013, -0.014]。
4. Adaptive 相对固定25%少用44.875%的 demo sample，平均 AULC 差为 -0.0006；seed0–4配对差为 [-0.022, -0.0035, +0.012, -0.0125, +0.023]，不是稳定胜出。
5. 时间衰减相对固定25%少用65.625%的示范，平均 AULC 差 +0.0009。当前没有显示出 Adaptive 相对简单时间衰减的明确优势。
6. 最终成功率接近上限，不宜只按均值排序宣布优越性。paired_uncertainty.csv 是5个 seed 的探索性配对 t 区间，未校正多重比较；区间跨0不证明方法等效，也不构成正式非劣性结论。
7. 固定25%的seed3最终测试93.5%，其中超时5%；这一个seed影响了测试均值。必须保留，不能当异常剔除。
8. 测试结果仅作为预先冻结实验的最终评估，不用于回头选择算法、阈值、checkpoint或训练预算。

目前观测到“示范组的早期退化检查点较少、平均早期适应效率较高，但seed间存在差异，动态阶段持续高比例示范未显示稳定的最终优势”。目前不支持“Adaptive明显优于固定比例或时间衰减”。原因分析仍需区分直接观测与机制猜测，现有对照不能证明示范冲突是唯一原因。

## 文件说明

- summary_*.csv：原实验逐seed、均值标准差、配对差异。
- additional_metrics_*.csv：早期AULC、首次达阈值步数、静态失败检查点、WAIT和耗时。首次50%可能为step0，因为部分foundation初始动态成功率已经超过50%；仅每10000步观测，不能当精确首次到达时间。
- 各 method/seed：training.csv、validation_curve.csv、validation_details.csv、test_details.csv、static_retention.csv、result.json、adaptive_schedule.csv及全部评估失败轨迹。
- actual_demo_sampling_intervals.csv：从完整逐batch日志核验后生成的无损区间表示，保留区间起止step、请求比例、实际整数配额、batch数和online大小；每个batch的增量update等于step。排除冗长逐batch CSV，不丢失采样配额信息。
- manifest.json、acceptance/、snapshot/：来源和验收记录，以及冻结时的实现与配置。snapshot只用于代码分析，未附二进制checkpoint；并非可直接重跑的完整训练备份。
- completion.json 中记录的是原始run所有文件哈希；其中部分大型文件未放入分析包，原始文件仍留在源实验目录。

未包含model_final.pth、checkpoint_final.pt和完整训练场景列表；没有修改源实验结果或任何算法参数。

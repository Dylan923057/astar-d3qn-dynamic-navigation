# TD单独控制与循环诊断：最终发现

2026-10-29 18:21，两个新增D3QN＋TD约束seed的训练、配对诊断和五方法报告全部完成。每seed固定500000在线环境步、499501更新，无离线/示范/教师、无失败或后处理错误，队列为空。旧8次运行直接复用；旧冻结、模型和原始日志校验通过。

所有方法使用相同冻结50任务动态验证，均取500000步最终模型。下表AULC是全程成功率曲线的归一化面积，±是两个训练seed的样本标准差。

## TD单独改善多少，教学组合还有多少收益

与同seed原始D3QN相比，仅加TD约束：成功率分别增加24、10个百分点，平均增加17个百分点；全程AULC分别增加11.84、8.38个百分点，平均增加10.11个百分点。平均碰撞20%→11%，超时66%→58%。这支持TD约束在当前设置/预算中具有作用，但仍有明显失败。

与TD-only相比，C成功率分别增加50、36个百分点，平均增加43个百分点；全程AULC分别增加31.66、30.64个百分点，平均增加31.15个百分点。超时58%→13%，碰撞11%→13%。因此，TD约束不能单独解释C的全部优势，教学组合仍有额外收益，但C并非所有安全指标都更好。

C−TD-only的差值只对应“A*动作代选＋持续动作监督”的组合，不能直接归于持续监督单项。不能把17与43的代数分解转成相互独立的因果贡献比例。逐seed、均值及样本SD见 [controlled_effects_per_seed.csv](controlled_effects_per_seed.csv) 和 [controlled_effects_mean_sample_sd.csv](controlled_effects_mean_sample_sd.csv)。

## 循环证据

| 方法 | 动态循环超时任务占比seed0/1 | 静态成功seed0/1 |
|---|---:|---:|
| 原始D3QN | 56% / 50% | 0% / 0% |
| D3QN＋TD约束 | 44% / 38% | 10% / 16% |
| DQfD | 66% / 46% | 16% / 20% |
| C | 16% / 6% | 74% / 74% |
| D | 24% / 24% | 60% / 66% |

循环超时比例的分母为每seed的全部50任务，不是仅超时任务。完整动态轨迹已补齐：C/D共184次缺失轨迹推断逐任务与原成功/碰撞/超时/步数一致，原成绩未改。四方法原有可用轨迹全部复用；新控制只新增100次静态配对，动态成绩复用其例行最终验证。

所有20个条件的1000条任务记录中，目标输入、独立BFS静态教师标签以及保存动作与当前最终网络贪心动作均未发现错配。C/D最终回放共80000条经验的当前/后继目标位移、零路线输入、教师动作和存储风险重算也未发现不一致。这些审计不能覆盖全部历史抽样，也不证明静态教师在动态环境中始终安全。

超时状态经常出现教师动作Q落后于其他合法动作乃至回退动作；完全相同观测多次出现时，五动作Q保持一致，贪心动作形成重复观测闭环。已保存350条满足观测后继唯一、至少重复3次条件的闭环记录；它们不是350次独立训练重复。这解释了执行层面为什么会反复走同一闭环，但形成这种Q排序的训练原因仍未确定。

D的动态循环超时比例高于C是补齐完整轨迹后的直接观察，仍不能直接归因为风险降权减少监督。评估始终没有监督，系数为0；CSV中C/D系数只是事后假设权重。

去掉动态障碍同时改变网络输入分布，静态配对不能替代单独静态训练。TD-only在静态仍仅10%/16%成功，基础多目标导航缺口仍在。

## 价值与预算

TD-only的Q绝对值峰值约11.83/11.63，原始TD目标上界约11.74/11.47，裁剪目标上界10；网络Q仍可超过10，说明没有错误裁剪Q输出。全部目标的实际裁剪比例约0.0532%/0.0381%；少数目标变化也可能改变后续更新与访问轨迹，不能仅根据裁剪比例小就认定机制无效。

原始及裁剪目标样本、Q、梯度和全部更新的区间统计保留在独立outputs中。主比较按相同在线步数进行，实际运行时长受资源占用与日志开销影响，不能把墙钟差异全部归于算法。

DQfD仍额外包含每seed20000离线更新和永久3472条示范，成功仅覆盖70/240训练任务及31/40目标；示范生成15107环境步成本由两seed共享。其低成绩不归因为未经支持的Q爆炸。

## DDQNA适配差异与控制变量

明确命名为“采用DDQNA动作选择机制的D3QN适配基线”，不声称原版完整复现。

| 项目 | 原论文已核对内容 | 本次适配 |
|---|---|---|
| 动作选择 | 概率ε随机、(1−ε)p为A*、(1−ε)(1−p)贪心，p=0.5 | 保留该分支顺序与固定p；训练不衰减教师 |
| 网络/动作 | FC网络、Dropout、8个输出动作 | 仓库CNN+Dueling Double DQN，5动作（上下左右等待），不用Dropout |
| 观测 | 原论文任务的观测定义 | 保持现有观测：局部静态与动态三帧，加零A*通道/零引导标量；网络5×15×15+4标量 |
| 地图/动态过程 | 多个10×10实验环境 | 同一40×40固定地图91701、相同起终点、全图路线池、每回合3–5动态障碍 |
| 教师实现 | A*动作指导；规划器动态信息权限、缓存细节未确认 | 复用仓库静态地图A*：只依赖当前位置、静态地图和目标；不读动态未来，不作动态风险否决；按当前位置缓存 |
| 静态合法约束 | 与本仓库完全相同的掩码未确认 | 三分支均使用共同静态合法掩码；无A*建议/建议静态非法时回退贪心，并记录回退数 |
| 奖励 | 论文式1包含碰撞/目标/移动/重复访问等项 | 保持仓库原奖励：步−0.01、曼哈顿进展×0.05、碰撞−1、目标+10、stay=0；不移植论文奖励 |
| TD损失 | 算法1平方TD误差 | 保持仓库普通D3QN Huber损失；无margin、额外监督、TD目标clip或PER |
| 预算/ε | 每环境2000回合，上限1000步；ε按回合衰减 | 200000在线环境步；300步/回合；ε=1→0.05，150000步衰减，与完整组合一致 |
| 优化与回放 | 论文设置 | 仓库Adam LR=3e−4、γ=0.99、64批量、回放10000、500步开始学习、每步1更新、目标同步250更新、梯度范数上限10 |
| 评估 | §4.2关A*、ε=0 | 同样关闭教师；复用原50验证与频率，以及已冻结500最终确认场景 |

网络、目标网络、优化器初始状态及学习器随机状态逐seed与保存的完整组合初始指纹配对。采用相同教师随机种子偏移，但策略分支会不同地消耗随机数；配对初始化不表示训练轨迹逐步相同。无离线预训练、无foundation加载、无示范池。

继承配置中的 `training_advice`/`value_repair` 是原设置的审计参考：适配代理不会执行旧代选、风险或监督函数。真正生效的策略在 `ddqna_adapter` 与独立代理中，普通TD函数直接继承D3QN。

## 评估、统计与成本（固定协议）

- 原50验证：初始点、每10000步按原回合边界触发、最终200000步，共21点。验证ε=0，明确关闭教师，保持网络/随机数/教师计数不变。新基线p=0.5不影响自主验证。
- AULC沿用实际检查点的线性插值与梯形积分，按环境步区间长度归一化；报告0–200000、100000–200000及0/80000/100000/140000/200000各阶段。
- 首次连续三个成功率≥90%的验证点：主指标取第一点实际步数，另列第三点确认步数；未达到记为空/未达到，不伪造200000。条件均值与SD须附达到seed数；配对步数只对两者均达到的seed有效。
- 统计单位是五个配对seed，均值±样本标准差（ddof=1），另列完整组合减适配基线的逐seed差值。不能用500场景当成500个独立训练样本。
- 最终确认只加载 `model_final.pth`（200000步），对两方法共10个模型使用普通D3QN评估，不使用检查点最优选择。沿用已冻结的500场景 `data/whole_map_91701_supervision_tail_v1/independent_final_scenarios.json`，SHA256 `051c083a8a185ac1738ad71debd3508cca7a20020319009eabe132062c130318`。该批原方法已评估，本轮复用同一场景集，不宣称新抽样的完全未见测试集，不从其结果调参。
- 报告成功率、动态碰撞率、超时率；保存全部失败轨迹，以既有规则区分等待/绕圈/其他超时，分类互斥。保留场景逐项结果。未来障碍信息只用于事后指标/轨迹诊断。
- 成本记录：A*查询次数（含缓存命中）、实际搜索次数（缓存未命中）、查询累计耗时、梯度更新数（正式在线199501）、在线训练耗时、验证/回调耗时、总墙钟耗时及设备。分支计数不从动作猜测，记录随机/教师/贪心的真正选择分支、概率质量、教师可用/回退次数。旧组合缺失的A*计数、耗时留空，已有梯度更新数保留；不据不完整成本声称计算效率最好。
- 训练入口默认仅检查。已有输出目录时拒绝覆盖/续训。分析与最终评估在全部五个新模型完成且协议审计通过前不创建输出。

## 已有证据与贡献边界

下列结论来自既有十一方法五seed报告与源码，不把尚未训练的DDQNA适配基线混入。原报告：[学习结果](../results/whole_map_91701_dqfd_comparison_v1/analysis_20261009_173936_175389/REPORT.md)、[最终500场景](../results/whole_map_91701_dqfd_comparison_v1/independent_eval_20261009_174147_641239/REPORT.md)。AULC/成功率均以百分点理解。

| 判断 | 已有证据 | 允许的解释/限制 |
|---|---|---|
| 完整组合提高既有在线指导的学习效率 | 原50全程AULC：完整91.37±1.05%，代选+TD约束60.44±2.30%；配对增益30.93个百分点、五seed均正 | 在这个既有对照里，加入匹配动作监督有效；不能直接当成对DDQNA的增益 |
| TD约束与动作监督存在组合效应 | 代选+监督35.74±5.34%，完整91.37±1.05%；代选无约束2.65±5.92% | 单独加入A*或监督不一定稳定；不能推广成所有任务都需要同一clip范围 |
| 代选在已有监督+约束基础上仍有增量 | 监督+约束83.02±4.07%，完整91.37±1.05%；配对+8.35±3.94个百分点 | 支持已有设置中的教学效率增益，需新基线检验近邻机制差异 |
| 动态风险筛选并未证明最终更安全 | 不筛选AULC90.42±3.86%，相比完整学习差值跨seed正负混合；最终500不筛选成功98.84±1.32%、碰撞0.60%，完整98.16±1.82%、碰撞1.84% | 可报告描述性学习稳定性差异；不能声称风险筛选保证安全或最终避障更优 |
| 尾段延期没有解决退出低谷 | 尾段全程AULC93.38±1.90%；14–20万步95.46±2.71%，原完整98.36±0.85%；四seed低谷后移，五seed晚段AULC均下降 | 原退出窗改善不代表解决；监督权重总面积+8%，还存在教学量/时序混杂 |
| DQfD是强对照，不能隐藏额外成本 | DQfD全程93.24±0.42%，DQfD+约束93.17±0.60%；7260永久动态执行示范、额外20000离线更新 | 学习效率接近或优于组合，但不是同总更新/教师数据成本。DQfD+约束最终500为99.20±0.77%，完整98.16±1.82% |
| 教师退出、自主测试本身不是贡献 | DDQNA训练固定p、测试关教师；本仓库退出后仍见回退/碰撞 | 不能声称首次自主测试、必须教学退出或已经解决退出低谷 |

建议贡献表述：在固定地图与动态障碍设置中，研究在线A*教学如何通过执行匹配的动作监督与完整TD目标约束加速D3QN自主学习；以配对消融、训练成本和最终自主确认评估量化收益及退出风险。新增DDQNA动作机制适配对比完成后再填入其增益，不预写胜出结论。与该适配基线的差值包含教学概率、退出日程、监督、TD约束及风险筛选的总差异，单模块归因依赖已有消融。

不使用“首次融合A*与DQN”“保证安全”“最终避障最好”“已解决退出低谷”“完整复现DDQNA”“跨地图泛化已证明”。

## 执行顺序（PowerShell，仓库根目录）

```powershell
python scripts/run_ddqna_adapter.py --train --seeds 0 1 2 3 4
python scripts/report_ddqna_adapter.py --analyze
python scripts/report_ddqna_adapter.py --evaluate
```

第一条顺序执行五次新训练；全部完成后再运行后两条。原方法不重训，最终评估复用其最终权重。检查入口：`python scripts/run_ddqna_adapter.py`；单元/8步接入检查：`python -m unittest discover -s tests -p test_ddqna_adapter.py -v`。

风险筛选不保证安全；教学延期不等于解决退出低谷；DDQNA全0不作为主要优势证据。统计单位是训练seed，单seed没有样本标准差。
旧方法缺少的真实TD误差分布、关键训练状态覆盖、A*计数和耗时继续标为缺失，不以冻结自举残差或Huber损失替代真实TD误差。

## 六组究竟比较什么

| 组 | 方法名 | 训练期A*代选探索动作 | TD目标限制 | 辅助动作监督 |
|---|---|---|---|---|
| 1 | unguided_raw | 无 | 无 | 无 |
| 2 | unguided_bound | 无 | [-6,10] | 无 |
| 3 | advice_raw | 有 | 无 | 无 |
| 4 | advice_bound | 有 | [-6,10] | 无 |
| 5 | advice_margin | 有 | 无 | 有 |
| 6 | advice_bound_margin | 有 | [-6,10] | 有 |

全部从随机网络开始，同seed六组完整初始化状态相同，不加载静态foundation。没有固定25%示范回放，也没有运行时把A*路线或子目标输入网络。额外路线通道与子目标标量保持零。六组都保留目标曼哈顿距离奖励，因此第1组应称“无A*原始D3QN”，不能称“无距离奖励D3QN”。

A*只在训练时根据当前位置和静态地图计算路线，帮助选择下一步动作。代选概率从0.8线性降到第100000步的0。风险筛选只读取当前与最近两帧动态观测；下一步教师格与其中障碍位置曼哈顿距离≤1时拒绝建议，回退普通epsilon-greedy，不强制等待，也不读取未来障碍路线。该筛选没有独立关闭对照，不能单独宣称它有效。

动作监督采用0.8 margin的辅助损失，使符合条件的A*动作Q高于其他静态合法动作：实际执行动作必须等于教师动作，观测风险筛选通过且转移未碰撞。监督权重从1线性降到100000步的0；这是额外损失，不是额外环境奖励，也不是完整DQfD。100000步之后所有教师应用、监督标签及监督权重均为0。TD目标限制持续到训练结束，只截断进入损失的目标，不直接截断网络Q输出。

## 相同训练与验证条件

- 固定40×40地图91701，起点(3,3)、终点(36,36)，静态最短路66步。网格SHA256：`789e02a19e945736e2ae78fa54163dd58e069df568d777f76577f6b8ccede0ff`。
- 全图动态路线池，每回合3–5个移动障碍；回合上限300步，碰撞终止。动作是上下左右与等待，屏蔽静态非法动作。
- 实际观测为15×15的静态障碍、当前动态障碍、最近两帧动态障碍四个通道，加两个目标位移标量。网络接口的第五通道与另外两个标量为零。
- 奖励：普通步`-0.01 + 0.05 × (旧目标曼哈顿距离 - 新目标曼哈顿距离)`；安全到达终点+10、碰撞-1，二者直接终止并替代普通步奖励；超时没有额外罚分。超时按截断处理，TD继续bootstrap。
- 每次200000环境步、199501梯度更新；epsilon从1降至0.05，衰减150000步；在线均匀回放容量10000、batch64、开始学习500步、gamma0.99、学习率0.0003、目标网络同步250次更新、梯度裁剪10。
- 全部验证使用同一[50个冻结场景](fixed_validation_scenarios.json)，epsilon=0，只有网络选动作，没有A*、风险保护或test数据。地图明细见[map_problem.json](map_problem.json)，完整参数见[effective_config.json](effective_config.json)。

| 组 | seed0–4最终安全成功率 | 最终安全均值 | 动态碰撞均值 | 超时均值 | 全程AULC均值±样本SD |

| 4 | 100 / 100 / 100 / 100 / 100% | 100% | 0% | 0% | 60.44%±2.30% |
| 5 | 98 / 0 / 98 / 14 / 40% | 50.0% | 4.0% | 46.0% | 35.74%±5.34% |
| 6 | 100 / 100 / 100 / 92 / 100% | 98.4% | 1.6% | 0% | 91.37%±1.05% |

AULC是按实际检查点步数对自主安全成功率作梯形积分后除以200000。第6相对第4组五seed均提高，平均差+30.93个百分点，优势主要在前期；首次记录到≥90%约1–2万步，第4组约9–12万步。首次达阈值不是稳定收敛。

第6组在引导退出附近五seed均下降，最低58%，后期恢复；完全退出后的后10万步阶段AULC为93.50%，第4组为97.52%。第6组seed3最终四次迎面动态碰撞：场景9、19、21、49。这些完整失败轨迹全部保留，不因组合组平均较好而剔除。第3、5组失败还包含等待和反复移动；分类可重叠，不应只凭超时率猜原因。

五个训练seed是统计单位，共用场景与重复检查点不能当独立重复。配对t区间是n=5、依赖正态假设、未经多重比较校正的探索性结果。当前不能宣称组合方案最终全面最好、未知场景普遍有效、风险筛选已被独立验证或超过已有论文方法；尚缺同条件外部基线和泛化实验。
